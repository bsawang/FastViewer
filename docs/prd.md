## 1. 项目定位

**自用的桌面图片浏览器**：打开电脑上的任意文件夹，把它里面的图片和视频当成一面图墙来看。

核心价值：

- **快**：打开文件夹就能看到全部内容，滚动、切图、拖视频进度都不等。
- **好看**：界面完全自绘，没有浏览器的地址栏、书签栏和多余的右键菜单；深色、干净、有质感。
- **够用**：系统里能直接显示的照片和常见视频都能看；不为了冷门格式折腾。

成功长什么样：打开一个装满照片的文件夹，从缩略图墙点进任意一张，键盘一路翻到底，全程不卡、不闪、不迷路；含视频的目录里，视频能直接播、能拖进度。

什么算失败：打开大目录时白屏或长时间转圈；翻图时出现明显空白等待；视频进度条拖不动；界面上露出"这是个套壳浏览器"的痕迹。

### M1 文件夹浏览 ✅

用户能做什么：

- 启动即进入文件浏览，顶级是**"此电脑"**：先列出**系统快速访问文件夹**（桌面 / 下载 / 文档 / 图片 / 音乐 / 视频，存在才显示），再追加**资源管理器"快速访问"中用户自己固定的文件夹**（按资源管理器顺序、去重、失效项隐藏），最后列出本机可用盘符，不需要先"选择/打开文件夹"，也没有欢迎页或选目录对话框。
- 从盘符逐级下钻，浏览完整目录：顶栏**面包屑**从"此电脑 › 盘符 › …"开始，点击任一级直接跳回。
- 图墙里同时包含**子文件夹**与**返回上级**两个入口；盘符根目录的"返回上级"回到盘符列表，盘符列表本身不出现该入口。
- 仍可直接跳转：拖入文件夹、启动时带路径、或在应用已运行时再次带路径启动。
- **双击媒体文件直接打开**：应用注册为系统“打开方式”后，双击图片 / 视频会启动（或复用已运行窗口）FastViewer，进入该文件所在目录，并在右侧查看器中直接显示这个文件。
- **图块大小可调**（小图块 ↔ 大图块连续可调，至少 4 档），调整后整面墙即时重排。
- **无限滚动**：滚到底部自动加载后续内容，没有"下一页"按钮，不打断滚动惯性。
- 缩略图**铺满图块**：顶部居中对齐，过高的图裁掉底部、过宽的图裁掉两侧；文件名以**半透明浮层压在图块底部**，**不限行数完整换行、向上生长**，不改变图块尺寸；悬停与选中状态清晰，选中项用**明显加宽的描边**突出。
- 查看器切换图片（键盘、滚轮或全屏浮层）后，图墙当前项高亮同步；若对应图块不在可见范围，图墙自动滚动将其所在行贴到顶部。
- 按名称 / 修改时间 / 大小排序，并可切换正序倒序；排序键与图块大小滑杆位于**面包屑下方**，图墙底部不再有工具条。
- 上千个文件的目录里滚动仍然跟手，缩略图随滚动逐步补齐，不出现整面空白。

对用户的价值：这是打开软件后的第一屏，也是"文件夹浏览"这一最高优先级需求的载体——第一屏就是文件系统本身，像资源管理器一样直接面向磁盘，不进入任何"导入/图库"流程。

### M2 大图查看 ✅

用户能做什么：

- **查看器常驻右侧**：打开文件夹即自动把第一张图片 / 视频载入查看器，图墙与查看器始终并排；没有可查看的媒体时右侧显示空态提示。
- 图墙与查看器之间的**分隔条可拖动**，随时调整两侧宽度；比例被记住，下次打开沿用。
- 查看器**不设顶部 / 底部文件名栏**；文件名、像素尺寸、文件大小、修改时间放在**右下角半透明浮动详情区**里（固定宽度、高度随内容自适应），默认显示、可关闭；关闭后右下角留下一个浮动按钮，随时重新打开。
- **点击查看器中的图片进入全屏**：全屏是**应用内模态半透明浮层**，不改变系统窗口（不隐藏标题栏所在窗口、不接管任务栏），退出后回到原来的常驻查看器。
- 全屏浮层内关闭按钮在右上角，左右两侧是圆形底的大号常驻切换箭头，详情区在右下角（可关闭）；**支持自由缩放**（Ctrl+滚轮缩放、双击在适应窗口与原始尺寸间切换、放大后拖拽平移），并提供 **1:1** 与**适应窗口（居中撑满）**两个按钮；普通滚轮切换图片。
- 全屏浮层内键盘 ← / → 切换上一张 / 下一张，Esc 关闭浮层；关闭后主窗体的查看器仍停在当前图片，并保持当前缩放状态。
- 查看器内键盘 ← / → 或普通滚轮切换同目录的上一张 / 下一张，Ctrl+滚轮缩放。
- 查看当前文件名、图片像素尺寸、文件大小（通过浮动详情区）。
- 连续翻图时相邻图片已提前备好，不出现明显的空白或闪烁。
- 遇到无法显示的文件，给出明确提示而不是空白画面。

对用户的价值：决定了"看图"这件事的手感；键盘翻页 + 缩放平移是自用场景下最常用的两个动作。

### M3 视频播放 ✅

用户能做什么：

- 同目录中的视频与图片排在同一面墙上，点击后在查看器内播放（不跳转到外部播放器）。
- 播放 / 暂停、音量、静音、播放进度与时间显示。
- 拖动进度条能立刻跳转到目标位置。
- 键盘 ← / → 与其他媒体共用（切换上一项 / 下一项），空格切换播放 / 暂停。

对用户的价值：混合目录（照片+手机视频）不必换个软件；"能拖进度"是判断播放器是否可用的底线。

### M4 界面与窗口 ✅

用户能做什么：

- 窗口顶部是应用自绘的标题栏与最小化 / 最大化 / 关闭按钮；拖动标题栏移动窗口，双击最大化 / 还原，贴边吸附等系统窗口行为照常可用。
- 标题栏只显示应用名与窗口按钮，**不显示当前路径或文件夹名**（位置信息由面包屑表达）。
- 主界面固定为三块：**顶部标题栏、左侧文件浏览区、右侧常驻查看器**，左右宽度可拖动调整。
- **窗体四角圆润**，最大化与沉浸态下自动贴合屏幕边缘。
- 提供**多套皮肤配色**（4 套深色 + 1 套浅色，其中包含暖色系深色），在标题栏**右上角自绘下拉菜单**即时切换，不使用系统原生下拉框，界面元素统一、克制；默认深色主题。没有浏览器的地址栏、标签栏、书签栏，也没有"检查元素 / 查看源代码 / 用浏览器打开"这类痕迹。
- 界面**控件图标**采用统一的**线性图标**风格（Heroicons outline），设置、盘符、排序、查看器与全屏控件视觉一致；**图墙文件夹图块使用自绘的填充式文件夹图标**（与控件线性图标形成区分，不使用 Heroicons）。
- 图墙选中项与查看器切换有短促的过渡，不闪白、不跳版。
- 窗口最大化与还原时布局正确，标题栏与内容一起适配；按钮在最大化状态下表达"还原"。
- 在高分屏与多显示器（缩放比例不同）下，界面不模糊、窗口拖动与最大化不发疯。

对用户的价值：这是"界面好看"这一第二优先级需求的直接兑现；也是用户每天面对时间最长的部分。

### M5 偏好与会话 ✅

用户能做什么：

- 记住上次打开的文件夹，下次启动直接回到上次的位置。
- 记住排序方式、图块大小、窗口位置与大小、当前皮肤配色。
- 在应用内打开一个轻量设置 / 关于面板：查看版本、清理偏好或恢复默认布局。

对用户的价值：自用工具不需要每次重新找目录、重摆窗口；打开即回到昨天的现场。

## 3. 非目标

明确不做（防止范围蔓延）：

- **不做图片编辑**：裁剪、旋转写回、调色、批量重命名、格式转换一律不做。
- **不做格式扩展**：不内置额外解码器；TIFF、HEIC、RAW、PSD、JPEG2000、QOI 等不保证可显示。系统/运行环境能显示的即可。
- **不做图库管理**：标签、评分、人脸识别、以图搜图、云同步、跨目录索引库都不做。
- **不做多标签 / 多窗口 / 双图对比**：一次一个文件夹、一个查看者；图墙与查看器的左右分屏不属于"双图对比"。
- **不做远程与网络目录**：SMB、网盘、FTP 等不纳入浏览范围。
- **不做触屏与手机端**：面向桌面鼠标键盘。
- **不做音频、文档、压缩包预览**：非图片非视频文件不在墙上出现（子目录除外）。
- **不做自动更新 / 更新服务器**：升级靠手动替换产物。
- **不首发 macOS / Linux**：仅 Windows。
- **不追求像素级无损的极冷门色彩空间**（如 CMYK TIFF）——属于格式扩展范畴，已排除。
- **不做系统级独占全屏**：“全屏”是应用内的模态浮层，不改变窗口状态、不隐藏任务栏。
